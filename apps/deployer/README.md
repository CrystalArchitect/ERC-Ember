# ERC-EMBER v1 deployer

Browser UI for atomically deploying the adminless factory suite, deploying flat-price projects, and reading the on-chain registry. SPDX text is always shown as developer-declared and unverified. Optional maintenance pools accept only contract governors and warn that tips are irreversible governor/timelock-trusted donations.

```bash
npm ci
npm audit --omit=dev
npm run build
```
