# Contributing

Open an issue before changing protocol economics or lifecycle rules. Contract changes must include unit and stateful-invariant coverage, pass formatting/tests/size checks, and update every affected ABI consumer and normative document.

Do not add fees, treasury recovery, upgrade authority, generic vote labels, or canonical x402/MCP paths without a separate reviewed specification. Never describe declarations or commitments as verified facts.

Use focused commits. Preserve unrelated worktree changes and include the exact verification commands and results in review notes.
