# Security policy

This reference implementation has not been represented as independently audited or production-ready. Do not deploy meaningful value before an independent economic/security review and full testnet lifecycle rehearsal.

Report vulnerabilities privately to the repository maintainers through GitHub private vulnerability reporting. Include affected commit, reproduction, impact, and a proposed mitigation if known. Do not include live secrets or exploit public deployments.

Canonical scope is `contracts/src` excluding explicitly experimental work. The x402 and MCP prototypes are not eligible for mainnet-security claims.
